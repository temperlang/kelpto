# WPT tree construction tests

kelpto-html's tree construction against web-platform-tests' tree
construction tests (`html/syntax/parsing/resources/*.dat`, which
html5lib-tests used to hold), at commit 4aa56d3beafc.

- **`tests.temper.md`:** the tests, generated by
  `scripts/wpt_tree_construction.py` from the `.dat` files, which it
  downloads into `data/` (not in git).
- **`tree-tests.temper.md`:** runs them: the tree each test expects,
  written in the files' dump format, and that every input roundtrips,
  with counts by file.

All 1,761 document tests pass, `<selectedcontent>` copying the
selected `<option>` (webkit02.dat) included, and all 206 fragment
tests (`#document-fragment`, parsed in their context element). The
runner checks that they all pass. In C++, one fails (`<?something ?\t   ?>`), since the
`temper` C++ backend writes `??>` into a string literal, which C++14
reads as a trigraph (`}`).

Not yet checked: error counts, since kelpto-html doesn't keep tree
construction's errors. Left out: the scripted_*.dat
files, which need a script engine.
