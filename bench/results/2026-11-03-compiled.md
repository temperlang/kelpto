spec-x10 wasn't run in C++: it would take minutes per parse. Kotlin
Temper's C++ passes a `String` by value (`std::string`), and copies a
string field into each local of it, so every helper that reads the
source by `StringIndex` (`codeInAt(text, at, end)`, once per code
point) copies the whole document: quadratic. Single cold parses of
the spec took 1.3 to 1.5 s. Needs Temper to pass strings by reference;
the Kelpto source is fine.
