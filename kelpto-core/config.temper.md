# kelpto-core

Lossless syntax trees shared by kelpto-md and kelpto-html: red-green
trees, spans, source text counted in code points, HTML's character
references, and the Unicode classes CommonMark needs. Most people never
name this library; they use kelpto-md, kelpto-html, or kelpto.

    export let name = "kelpto-core";
