# kelpto-md

Lossless Markdown: parse a document, change one part, and print it
back with everything else exactly as written; render it to HTML with
raw HTML escaped unless the caller trusts it. All of CommonMark
0.31.2, and GitHub Flavored Markdown's extensions (see the README).

    export let name = "kelpto-md";
    export let license = "Apache-2.0 OR MIT";
