Muscle memory for AI. Solve it once in Temper, and every language remembers.

Change one part. Keep every byte.

Kelpto parses Markdown into a tree that remembers how it was written. Change a heading, a table cell, a task, or a link, and write the file back with everything else exactly as it was: same spacing, same markers, same mess. Its raw HTML parses as browsers parse it, so Markdown from anyone renders safely. In C++, C#, Java, JavaScript, Lua, Python, and Rust.

✓ All of CommonMark 0.31.2's examples pass, and all of GitHub Flavored Markdown's, from cmark-gfm's spec and tests.

Beta: Temper and the libraries made with it, Kelpto included, are in beta. APIs may still change.

Edit it. Diff it.

Type or paste Markdown. Then click a heading, a table cell, a task box, or a link in the preview to change it through Kelpto's API, live in this page. The output differs from your input only where you edited.

Safe for Markdown from anyone.

        

          renderSafe doesn't judge tags one at a time. It
          builds the tree a browser builds from the rendering, Markdown and
          raw HTML together, keeps only what its policy allows, and checks
          every URL. So pieces that only do harm together are caught too,
          and what it gives is checked to parse back to itself.
        

        

           hostile inputs, rendered by this build of Kelpto

Kelpto in your view function

        

          If you build pages from state, as with htpy, maud, j2html, or
          React-style views, Kelpto renders the documents inside a view,
          not the view itself: parse and sanitize each post once per text,
          and drop the HTML into your layout.
        

        

        

      

    


    

    

      

        
The tour, in seven languages

        

          One program through Kelpto's API, written in each language:
          parse and print back, edit one part, render, GFM, footnotes,
          walk, build, and rearrange; then HTML, as a document and as a
          fragment, Markdown and its raw HTML as one tree, and rendering
          Markdown from anyone. Every version prints exactly the same text.
